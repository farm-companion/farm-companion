## Decisions

Rejected volume copy because it would have required matching the exact `supabase/postgres` image on Hetzner and dealing with the `supabase_admin` role.
- **Port 5432 + Coolify SSL + Vercel `sslmode=require`, not port 4 / plaintext**: user initially picked port 4 and it worked, but standard 5432 + SSL is what every future debugger expects. Made the change tonight while the user was already in Coolify.
